
# Dashboard | Chart.js

Atividade de **Pesquisa e Inovação — SPTech**, criação de um Dashboard com uso da ferramenta: **Chart.js.**

A Dashboard contêm  três gráficos: **linhas, barras e doughnut**, sendo o grafico de doughnut, o desafio da videoaula.

### Como executar

Clone ou baixe o repositório; dentro da pasta do projeto, execute:

```bash
npm install
```

Depois, abra o arquivo `index.html` no navegador.
